## ✨ 功能特性

这是一个交互式的 **8参数透视变换可视化工具**，让你直观地理解 2D 图形变换的数学原理。

### 8个可控参数

| 参数 | 范围 | 说明 |
|------|------|------|
| **平移 X** | -300 ~ 300 | 水平方向移动 |
| **平移 Y** | -300 ~ 300 | 垂直方向移动 |
| **旋转** | -180° ~ 180° | 绕原点旋转 |
| **缩放 X** | 0.1 ~ 3 | 水平方向缩放 |
| **缩放 Y** | 0.1 ~ 3 | 垂直方向缩放 |
| **剪切 X** | -2 ~ 2 | 水平方向剪切 |
| **剪切 Y** | -2 ~ 2 | 垂直方向剪切 |
| **透视 X (p1)** | -0.5 ~ 0.5 | **关键参数：产生透视效果** |
| **透视 Y (p2)** | -0.5 ~ 0.5 | **关键参数：产生透视效果** |

### 核心特性

- 🎯 **实时预览**：拖动滑块即时看到变换效果
- 📐 **矩阵显示**：实时显示 3×3 变换矩阵
- 🔷 **多种形状**：正方形、三角形、五角星、房子
- 🎬 **动画演示**：一键播放旋转动画
- 📋 **代码导出**：复制变换矩阵为 JavaScript 代码
- 🖱️ **鼠标坐标**：实时显示鼠标在世界坐标系中的位置

## 🚀 使用方法

### 方式一：直接打开（最简单）

1. 找到项目文件夹 `affine-transform/`
2. **双击 `index.html`**
3. 浏览器会自动打开，开始使用！

### 方式二：使用 VS Code Live Server（推荐开发时使用）

1. 在 VS Code 中打开项目文件夹
2. 安装 **Live Server** 扩展（如果还没装）
3. 右键点击 `index.html` → **"Open with Live Server"**
4. 浏览器会自动打开，并且保存文件时会自动刷新

### 方式三：使用 Python 简单 HTTP 服务器

```bash

cd affine-transform

# Python 3
python -m http.server 8000

# 然后浏览器访问 http://localhost:8000
```

## 🎮 操作指南

### 基本操作

1. **选择形状**：点击右侧的「正方形」「三角形」等按钮
2. **调整参数**：拖动滑块改变变换参数
3. **观察效果**：左侧画布实时显示变换后的图形
4. **查看矩阵**：右侧面板显示当前的 3×3 变换矩阵

### 透视变换的秘密

**透视变换的关键在于 `p1` 和 `p2` 两个参数。**

当你把 `p1` 或 `p2` 设为 **非零值** 时，奇迹发生了：

- 正方形变成了**梯形**
- 平行线开始**相交**
- 产生**近大远小**的透视效果

这就是 **8参数透视变换** 的威力所在——比普通的 6参数仿射变换多了 **2个自由度**，却能创造出完全不同的视觉效果！

|------|------|
| 🔄 重置 | 所有参数归零，回到初始状态 |
| ▶️ 动画演示 | 播放 360° 旋转动画 |
| 📋 复制矩阵 | 将当前变换矩阵复制为 JavaScript 代码 |

### 数学原理

#### 3×3 变换矩阵

```
| a  b  tx |
| c  d  ty |
| p1 p2  1 |
```

- **a, b, c, d** - 线性变换（旋转、缩放、剪切）
- **tx, ty** - 平移
- **p1, p2** - **透视参数**（关键！）

#### 透视除法

齐次坐标 `(X, Y, W)` 转换为笛卡尔坐标 `(x, y)`：

```
x = X / W
y = Y / W
```

其中 `W = p1*x + p2*y + 1`

**当 p1 或 p2 不为 0 时，W ≠ 1，产生透视效果！**
